# 🔴 TODAY LIVE NEWS

A modern, high-speed, bilingual (Hindi + English) Live News Portal with automated AI news generation, real-time Google News RSS sync, interactive UP district filter, full-page article reader, and admin dashboard.

---

## 🚀 Live Website URL
- **Website**: [http://localhost:5000](http://localhost:5000)
- **Admin Panel**: Click **"🛡️ एडमिन पैनल"** on the top right header (or visit with PIN: `1234`)

---

## 🌟 Key Features

### 1. 🌐 Bilingual (हिंदी + English)
- One-click language switcher (`हिंदी / English`) in the top navigation.
- Switches all navigation, categories, dates, and bilingual article contents instantly.

### 2. 🔴 Automatic Breaking News Ticker
- Pulsing red `बड़ी ख़बर / BREAKING NEWS` ticker bar.
- Auto-rotates active breaking news headlines.
- Click any headline to jump straight to the full story.
- Previous / Next navigation controls.

### 3. 🏙️ Categories & Uttar Pradesh District News
- 🏠 **Home (होम)**
- 🇮🇳 **India (भारत)**
- 🏛️ **Politics (राजनीति)**
- 🌎 **World (विदेश)**
- 🏏 **Sports (खेल)**
- 💼 **Business (व्यापार)**
- 🎬 **Entertainment (मनोरंजन)**
- 💻 **Technology (तकनीक)**
- 🏙️ **Uttar Pradesh (उत्तर प्रदेश)**
- 📍 **District News (जिला समाचार)**: Filter news by **Lucknow, Varanasi, Gorakhpur, Kanpur, Prayagraj, Ayodhya, Meerut, Agra, Noida, Ghaziabad, Bareilly, Jhansi**.
- 🔴 **LIVE / Breaking News (लाइव ब्रेकिंग)**

### 4. 📖 "Read More" Article Page
- Full-screen distraction-free reader mode.
- **Audio Text-to-Speech (ख़बर सुनें)**: Listen to news spoken in clear Hindi or English!
- **Font Size Adjuster**: `A`, `A+`, `A++` for easy readability.
- **One-Click Social Share**: Direct share to WhatsApp, X (Twitter), Facebook, and Copy Link.
- **Related News**: Relevant stories from the same category.

### 5. 🤖 "AI Se Sab News Add Ho" (Automated AI News Adder)
- In the Admin Panel, click **"⚡ Auto-Generate with AI"**:
  - Choose Category, target District, and number of articles.
  - Enter optional custom prompt (e.g. `UP Metro expansion`, `Cricket series`, `Stock market`).
  - Generates realistic, well-researched, bilingual news articles in seconds!
  - Fully supports Google Gemini API or runs on built-in smart AI synthesis without any API key required.

### 6. 📡 Live News API & Google News RSS Sync
- Click **"📡 Fetch Live RSS Feeds"** in the Admin panel to pull real-time headlines directly from Google News India / BBC feeds and publish them instantly!

### 7. 🛠️ Complete Admin Panel
- **Default PIN**: `1234`
- **Add / Edit / Delete news** with rich text content.
- **Image Upload**: Upload images directly from your computer or provide image URLs.
- **Breaking News Toggle**: Turn any news into a breaking news headline in 1 click.

---

## 💻 How to Run

### Method 1: Double Click
Simply double-click `start.bat` on your desktop!

### Method 2: Command Line
```bash
# In c:\Users\User\Desktop\today live news:
npm start
```
Then open `http://localhost:5000` in any web browser.
